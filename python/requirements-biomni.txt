# Interpreter contents for the run_python worker.
#
#   python3.11 -m venv .venv
#   .venv/bin/pip install -r python/requirements-biomni.txt
#
# Then point the plugin at it. Easiest is Settings -> Biomni in the web UI;
# equivalently, write it into the settings document ($DSH_HOME/settings.yaml):
#
#   biomni:
#     python: /abs/path/to/.venv/bin/python
#
# Either applies without a restart. To set the DEPLOYMENT default instead, use
# your profile's own patch layer ($DSH_HOME/profiles/<name>/cordis.patch.yml).
#
# Run /biomni, or open Settings -> Biomni, to see what this actually bought:
# which modules import, and which functions are callable. They are not the
# same number.
#
# Biomni declares only pydantic, langchain, and python-dotenv. Everything below
# is undeclared: found by reading its source, and required for its tools to
# import or run. Two separate mechanisms are at work, and both bite.
